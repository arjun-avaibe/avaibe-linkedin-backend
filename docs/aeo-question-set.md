## 3. Method: making results comparable

1. **Same wording every time.** Even small changes alter answers.
2. **Fresh session, signed out** (or a clean chat with memory/personalisation off) so history doesn't bias answers.
3. **Run each question 3 times** per assistant per month: answers vary, so count how often AVAIBE appears (0/3 to 3/3).
4. **Same day each month**, and note the assistant and model version.
5. **Record for each answer:**
   - Is AVAIBE mentioned? (yes/no)
   - Position in the list (1st, 2nd…) or "mentioned in passing"
   - How it's described (accurate / inaccurate / outdated), plus the exact sentence
   - Competitors named
   - Sources or links the assistant cited (these show which pages AI trusts)
6. **Don't over-read a single month.** Look at the trend over 3+ months.

## 4. What the app will show

- **Mention rate** per question and per assistant (e.g. "C5: 2 of 9 runs this month, up from 0 last month")
- **Share of voice:** AVAIBE vs competitors named across all answers
- **Description accuracy:** are AI assistants describing AVAIBE correctly?
- **Cited sources:** which websites AI relies on, i.e. where AVAIBE needs a presence
- **Suggestions** (same format as now: why / boost / risk / confidence / measure), e.g. "Publish a clear FAQ page
  answering 'What should UAE schools look for in an LMS?'. Assistants currently cite competitor pages for this."
